# Operational MIS Dashboard with SLA & CSAT Tracking

## Project Overview

This project demonstrates the design and development of an interactive Management Information System (MIS) dashboard for customer support operations using Microsoft Excel. The dashboard transforms raw call center data into actionable business insights by tracking operational KPIs, SLA performance, agent productivity, customer satisfaction, and ticket trends through automated reporting and interactive visualizations.

---

## Business Problem

Customer support teams often rely on manual reports to monitor operational performance, making it difficult to track SLA compliance, agent productivity, ticket trends, and customer satisfaction efficiently. This project provides a centralized MIS reporting solution that automates KPI reporting and improves operational visibility.

---

## Solution

Designed an end-to-end Excel MIS Dashboard using:

- Pivot Tables
- Pivot Charts
- Power Query
- Slicers
- Advanced Excel Formulas
- Conditional Formatting

The dashboard provides dynamic filtering and interactive reporting across multiple operational metrics.

---

## Dashboard Modules

### 📊 Overview
- KPI Cards
- Ticket Trend Analysis
- Ticket Distribution by Process

- Average CSAT by Agent

### ⚙️ Process
